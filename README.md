## 📌 Sobre o Projeto

O projeto consiste no desenvolvimento de uma **loja virtual fictícia**, criada como atividade avaliativa da disciplina de **Web 1**.

A proposta foi desenvolver a interface completa de uma loja utilizando exclusivamente **HTML5 e CSS3**, sem o uso de frameworks, JavaScript ou PHP.

O projeto contempla páginas interligadas para apresentação dos produtos, detalhes individuais e simulação de um carrinho de compras.

### 🎯 Objetivo

Aplicar na prática os principais conceitos de desenvolvimento web apresentados na disciplina, com foco em:

- Estruturação semântica com HTML5
- Estilização com CSS3
- Organização e navegação entre páginas
- Desenvolvimento de layouts responsivos
- Utilização de Flexbox e/ou CSS Grid
- Aplicação de recursos de acessibilidade e usabilidade

---

## 🎨 UX/UI

## ✨ Funcionalidades

- ✅ Página inicial com categorias e produtos em destaque
- ✅ Página individual para detalhes dos produtos
- ✅ Página de carrinho de compras
- ✅ Exibição de quantidades e valores dos produtos
- ✅ Cálculo visual dos valores totais
- ✅ Mínimo de 4 páginas HTML interligadas
- ✅ Menu de navegação
- ✅ Conteúdo multimídia
- ✅ Layout responsivo para dispositivos móveis
- ✅ Efeitos de interação com CSS

> **Observação:** por se tratar de um projeto acadêmico focado em HTML e CSS, a loja possui caráter exclusivamente visual e não realiza operações reais de compra.

## 📱 Responsividade

A responsividade foi um dos principais requisitos do projeto.

A interface foi desenvolvida para proporcionar uma experiência adequada em diferentes tamanhos de tela:

- 📱 Dispositivos móveis
- 📲 Tablets
- 💻 Desktops

Foram utilizados recursos como **Flexbox, Grid, Media Queries e unidades relativas** para adaptar o layout aos diferentes dispositivos.
